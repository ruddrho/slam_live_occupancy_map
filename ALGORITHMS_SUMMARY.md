# Algorithms Summary

## 1. Interactive destination

MATLAB `ginput(1)` captures the clicked coordinate. The selected point is validated against the robot footprint and obstacles. A large red star remains visible throughout navigation.

## 2. Exact differential-drive integration

For near-zero angular velocity, the robot moves in a straight line. For nonzero angular velocity, the pose update follows the exact circular arc generated by constant `v` and `omega`.

## 3. Exact LiDAR intersection

- Walls, rectangles, and polygons: ray-segment intersection.
- Cylinders: quadratic ray-circle intersection.
- Nearest positive intersection: reported range.

## 4. Dynamic Window Approach

The dynamic window is the intersection of:

- physical velocity limits,
- acceleration-reachable velocity limits.

Each sampled command is rolled out over a short prediction horizon.

## 5. Safety filtering

A trajectory is valid only when:

- predicted center clearance exceeds robot radius plus margin,
- stopping distance fits within the available clearance,
- the predicted robot center remains inside the environment.

## 6. DWA objective

Valid trajectories are ranked using normalized measures of:

- goal heading,
- progress toward the goal,
- clearance,
- velocity,
- smoothness,
- steering moderation,
- stopping safety,
- goal proximity.

## 7. Local recovery

When distance-to-goal progress stalls, the controller temporarily increases clearance and local turning preference toward the more open LiDAR side. This is not global planning and does not generate a path.


## Hybrid A* and DWA correction

A* searches an 8-connected inflated occupancy grid and prevents diagonal
corner cutting. The resulting route is simplified only when the complete
line segment remains free, then resampled uniformly. The path follower
maintains a non-decreasing progress index and selects a target by walking
forward a fixed arc-length distance. DWA tracks that local target using
the current LiDAR point cloud. If path progress stalls or cross-track
error becomes excessive, a new A* route is generated from the current
robot pose.


## Segment-projection look-ahead

For every update, the robot is orthogonally projected onto nearby path
segments. Arc-length progress never decreases. A dynamically interpolated
look-ahead target is selected using current speed and cross-track error.
DWA candidate trajectories receive an additional score based on their
predicted distance from the path centreline.

## SLAM occupancy-grid update

The pose estimate is first predicted from noisy differential-drive
odometry. A small translational and rotational search aligns current
LiDAR hit endpoints with existing occupied log-odds evidence. Bresenham
ray traversal marks free cells, while LiDAR endpoints increase occupied
log odds. Probabilities are rendered continuously in the SLAM panel.
